# Product brief

## Ideal first customer

An MSP, agency, or small SaaS team with 1–10 engineers that already has backups but cannot confidently answer:

1. Did the backup run?
2. Is the artifact fresh and intact?
3. Can the application be restored?
4. How long would recovery take?
5. Can we show a customer, auditor, or insurer evidence?

## Positioning

Recovery Proof Kit is a recovery-evidence layer, not a backup provider and not a generic uptime monitor.

## Must-have outcome

Within 30 minutes, a technically competent operator should be able to produce a report showing:

- backup identity and timestamp;
- freshness result;
- size and digest result;
- storage and encryption assumptions;
- restore-test status;
- RPO and RTO targets;
- failed checks and remediation notes.

## What not to build initially

- A replacement for Veeam, Acronis, Datto, or cloud backup systems.
- A generic cron heartbeat clone.
- A dashboard requiring customers to upload backup data.
- An AI agent with permissions to mutate production or backup storage.
- A compliance certification or guarantee.

## Proposed pricing test

- Starter kit: $49 one-time.
- Professional kit with adapters and report templates: $149 one-time.
- Hosted evidence and multi-client reporting: test $29–$79/month.

These are validation prices, not final pricing. Ask for payment before adding large features.
