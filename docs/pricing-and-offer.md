# Initial offer

## Beta offer

**Recovery Proof Beta — $19 fixed price**

Includes:

- the complete starter kit;
- one setup walkthrough;
- artifact verification setup;
- recovery manifest review;
- one isolated restore-test plan;
- one Markdown evidence report;
- prioritized remediation list;
- no upload of backup contents.

Excludes:

- production changes;
- managed backup services;
- 24/7 incident response;
- compliance certification;
- storage or cloud charges;
- legal, tax, or insurance opinions.

## Self-serve version

**Community Edition — free**

Includes the local scripts, examples, and documentation. This is the lead-generation version and should be useful enough to create trust.

## Guided pilot

**Recovery Proof Pilot — $79 fixed price**

Use this only when the customer wants hands-on setup. It includes one 60-minute working session and one follow-up report review. Do not sell it before the free or $39 version has demonstrated a real gap.

## Product-only offer

**Professional Kit — $59 one-time**

Includes the scripts, templates, report generator, examples, and version updates for 12 months.

## Future hosted offer

Only build this after paid pilots request it:

- $19/month for one environment;
- $49/month for up to ten environments;
- custom MSP pricing for multi-client reporting.

The hosted service should receive status metadata and reports, not backup contents.
